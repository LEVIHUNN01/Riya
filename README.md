# Riya Birthday Gift 💗

A cute mobile-first birthday surprise website.

## Files
- index.html
- style.css
- script.js

## GitHub Pages
1. Create a new GitHub repository.
2. Upload these 3 files to the repository root.
3. Open Settings → Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select the main branch and "/" (root), then Save.
6. GitHub will give you a public website link.

The music is an original Web Audio melody generated by JavaScript, so no copyrighted song file is included.
